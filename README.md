# Hush 安装包

这里只发布 Hush 的安装包，源代码不在这个仓库。

## 下载

到 [Releases](../../releases) 页面下载最新版本：

- Apple 芯片的 Mac：`Hush-<版本>-mac-arm64.dmg`
- Intel 芯片的 Mac：`Hush-<版本>-mac-x64.dmg`

Windows 版暂未发布。

安装后，App 会从这里自动检查并安装更新。

## 每个版本还附带

- `SHA256SUMS.txt`：所有文件的校验值
- `Hush-<版本>-THIRD_PARTY_NOTICES.txt`：第三方软件声明
- `Hush-<版本>-sbom.cdx.json`：软件物料清单（CycloneDX）
- FFmpeg、LAME、Opus 的源码包：App 附带的 FFmpeg 按 LGPL 授权，对应的源码放在同一个版本里
